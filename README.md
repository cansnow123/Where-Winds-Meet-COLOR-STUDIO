# 燕云十六声 彩字工坊 Where Winds Meet COLOR-STUDIO

一个纯静态、本地可直接打开的燕云彩字编辑工具，围绕“输入文案、选中文字、设置颜色、复制结果”这条主流程设计。

## 功能亮点

- 可视编辑：直接在编辑区输入、粘贴、框选文字并上色
- 颜色模式：支持快捷色、单色、双渐变、多色渐变
- 实时预览：编辑区即所见即所得
- 一键复制：导出为游戏可用的颜色标签文本
- 本地运行：无需安装依赖、无需后端服务

## 直接使用

1. 打开 [index.html](./index.html)
2. 输入或粘贴文案
3. 选中文字后选择颜色或渐变模式
4. 在底部复制最终彩字结果

## 游戏颜色前缀语法

- 快捷色：预置颜色会导出为单字母前缀，例如 `#R你好`、`#G青山`。
- 自定义单色：自定义颜色会导出为十六进制前缀，例如 `#ff6a3d你好，我是你师傅`。
- 渐变色：渐变会根据色程压缩为多个颜色段，例如 `#ff6a3d邀我#ef8056入画#ffd166`。

## 导出规则

- 颜色代码统一输出为小写 hex，例如 `#ff0000`
- 同色文本只在颜色开始处输出一次颜色前缀，跨空格、标点时不会重复补写
- 渐变文本会按色程智能压缩为有限颜色段，避免逐字插入过多前缀
